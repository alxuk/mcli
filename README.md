# Installation
1. Download the release.
2. Make the file executable `chmod +x mcli`.
3. Run any `./mcli` command!

# Commands
- `-h` - shows how to use MCLI.
- `versions` - shows every available Minecraft version.
- `install` - installs a new instance of Minecraft.
- `launch` - launches an instance of Minecraft.
